Create a Custom Trust Policy
  1. Log into your AWS Console and navigate to IAM > Roles.
  2. Click Create role and select Custom trust policy.
  3. Delete the default text and paste the exact code below.
trust-policy.json 
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "AWS": "arn:aws:iam::396502421501:root"
            },
            "Action": "sts:AssumeRole"
        }
    ]
}
Add Read-Only Permissions
  1. Click Next.
  2. In the permissions search bar, type ViewOnlyAccess and check the box next to it.
  3. Click Next, give your role a name, and click Create role.
